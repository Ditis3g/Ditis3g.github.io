텍스트와 이미지는 복사하기 쉽지만 로봇 행동은 그렇지 않다. 로봇을 준비하고, 작업 공간을 초기화하고, 사람이 조종하고, 실패한 시도를 분류하고, 장비가 안전한지 확인해야 하나의 학습 경험이 완성된다.

## 한 번의 시범에 들어가는 시간

| 단계 | 실제로 필요한 일 |
| --- | --- |
| 준비 | 로봇·카메라·도구·작업물을 점검 |
| 초기화 | 물체와 로봇을 시작 상태에 배치 |
| 시범 | 사람이 목표를 수행하고 행동을 기록 |
| 리셋 | 실패하거나 끝난 작업을 다시 시작 상태로 복구 |
| 검수 | 센서 누락·동기화 오류·실패 원인을 확인 |
| 보관 | 개인정보·안전·버전 기준으로 데이터 관리 |

## 행동 데이터는 전용 경험이 되기 쉽다

같은 수건 접기라도 로봇의 팔 길이, 그리퍼의 모양, 카메라의 위치가 달라지면 관측과 행동의 관계가 바뀐다. 기존 데이터가 쓸모없어진다는 뜻은 아니지만, 그대로 복사해 새 몸에 적용할 수 있다고 가정해서는 안 된다.

| 바뀌는 요소 | 함께 달라질 수 있는 것 |
| --- | --- |
| 로봇 몸 | 관절 위치, 도달 범위, 가능한 경로 |
| 도구 | 접촉점, 힘, 물체를 잡는 방식 |
| 카메라 | 보이는 각도, 가림, 화면 속 위치 |
| 작업물 | 재질, 무게, 변형, 실패 양상 |

그래서 행동 데이터는 “이 로봇과 이 카메라가 함께 만든 전용 경험”이 되기 쉽다. 데이터의 양만 늘리는 것보다, 어떤 조건이 기록에 포함되어 있는지와 다른 조건으로 옮길 수 있는지를 함께 관리해야 한다.

## 비용을 줄이는 방향

비용을 줄이는 방법은 사람을 무조건 빼는 것이 아니다. 실패가 잦은 사례에 사람의 개입을 집중하고, 반복적인 조건은 자동화하거나 시뮬레이션으로 늘리고, 재사용 가능한 표현을 남기는 방향이 현실적이다.

다음 장에서는 실패한 시도를 버리지 않고, 사람이 개입해 복구한 과정을 새로운 학습 데이터로 바꾸는 방법을 살펴본다.

## 데이터 비용은 촬영 시간보다 넓다

행동 데이터의 비용을 카메라를 켜 둔 시간으로만 계산하면 실제 부담을 과소평가하게 된다. 로봇을 초기 위치로 되돌리고, 물체를 다시 배치하고, 센서와 조종기의 시간을 맞추고, 실패 영상을 검토하고, 안전한 실험을 감독하는 사람까지 모두 비용에 포함된다.

```text
시범 비용 = 준비 + 조종 + 리셋 + 동기화 + 선별 + 검증 + 장비 점유
```

특히 실패 사례는 성공 사례보다 검토 비용이 높다. 무엇이 잘못됐는지, 어느 시점에서 개입했는지, 다시 시도할 가치가 있는지 판정해야 하기 때문이다. 그러나 실패를 버리면 모델은 현실에서 마주칠 경계 상태를 배울 기회를 잃는다.

## 어떤 데이터를 먼저 모을 것인가

모든 조건을 같은 비율로 수집하는 것은 효율적이지 않다. 이미 잘하는 평범한 장면보다 실패가 집중되는 조건, 목표 달성에 결정적인 단계, 다른 작업에도 재사용될 수 있는 행동을 우선할 수 있다.

| 우선순위 | 데이터 예시 | 이유 |
| --- | --- | --- |
| 높음 | 자주 실패하는 가림·미끄러짐 | 현장 손실을 바로 줄임 |
| 높음 | 여러 작업에 공통인 접근·파지 | 재사용성이 큼 |
| 중간 | 새로운 물체·조명 조합 | 일반화 범위 확대 |
| 낮음 | 이미 반복 성공하는 동일 장면 | 추가 정보량이 작음 |

이것은 데이터를 적게 모으자는 뜻이 아니다. 한 번의 시범이 어떤 불확실성을 줄이는지 계산하자는 뜻이다. 데이터셋은 파일 모음이 아니라 다음 실험의 우선순위를 알려 주는 지도여야 한다.

## 몸과 도구가 바뀌면 비용이 다시 생긴다

같은 작업이라도 카메라가 바뀌면 화면의 위치와 시야가 달라지고, 그리퍼가 바뀌면 접촉과 힘의 관계가 달라진다. 새 로봇에 과거의 행동을 옮길 때는 관절 수만 맞추는 것으로 충분하지 않다. 장면과 물체 상태를 재현하고, 새 몸의 궤적과 센서 관측을 다시 연결해야 한다.

재사용 가능한 데이터는 작업 의미와 몸에 묶인 세부 행동을 분리해 보관한다. “수건의 모서리를 잡는다”는 의미는 여러 몸에서 공유할 수 있지만, 그 의미를 구현하는 관절 변화와 카메라 좌표는 몸마다 다시 계산해야 한다. 이 분리가 잘되어 있을수록 새 장비 도입 비용을 줄일 수 있다.
