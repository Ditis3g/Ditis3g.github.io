모델 계보는 이름을 외우기 위한 연표가 아니다. 각 모델이 입력을 어떻게 받고, 행동을 어떻게 다루며, 어떤 범위의 일반화를 시도했는지를 보면 VLA가 어떤 문제를 계속 풀어 왔는지 보인다.

| 흐름 | 핵심 관심사 | 이 책에서 볼 포인트 |
| --- | --- | --- |
| RT-1 계열 | 로봇 경험에서 행동 정책 만들기 | 여러 작업을 하나의 정책으로 다루려는 출발 |
| RT-2 계열 | 웹의 시각·언어 지식과 행동 연결 | 의미가 실제 행동으로 이어지는 가능성 |
| OpenVLA 계열 | 공개 모델과 행동 데이터의 결합 | 연구·재현·확장 가능한 기반 |
| π0 등 후속 흐름 | 행동 생성과 정밀한 실행의 결합 | 연속 행동과 실행 품질의 문제 |

이 구분은 각 모델이 모든 문제를 해결했다는 뜻이 아니다. 어떤 모델은 행동 데이터의 다양성에, 어떤 모델은 웹 지식과의 연결에, 어떤 모델은 실행 표현과 속도에 더 집중한다.

## 계보를 읽는 세 질문

1. 입력은 장면과 지시를 어떻게 표현하는가?
2. 출력은 정해진 행동 선택인가, 연속적인 움직임인가?
3. 같은 몸에서 여러 작업을 하는가, 여러 몸과 작업으로 확장하려 하는가?

모델명을 봤을 때 이 세 질문을 던지면 유행하는 이름의 나열을 넘어서 기술적 차이를 읽을 수 있다. 다음 장부터는 세 번째 질문을 이해하기 위해 행동 자체를 숫자로 펼쳐 본다.

## 모델군을 비교하는 실제 기준

같은 VLA라는 이름 아래에도 입력·출력·몸의 범위가 다를 수 있다. 어떤 시스템은 한 로봇의 몇 가지 작업을 안정적으로 수행하는 데 집중하고, 어떤 시스템은 여러 로봇의 데이터를 한 모델에 모아 의미와 행동의 공통 구조를 찾으려 한다. 전자는 실행 검증이 쉬울 수 있고, 후자는 데이터 정렬과 몸의 차이를 다루는 부담이 커진다.

| 비교 축 | 좁은 범위의 시스템 | 넓은 범위의 시스템 |
| --- | --- | --- |
| 몸 | 특정 로봇·센서 | 여러 로봇·센서 |
| 작업 | 정해진 작업군 | 다수 작업·언어 조합 |
| 출력 | 특정 행동 공간 | 공통 또는 변환 가능한 공간 |
| 장점 | 검증·제어 연결이 명확함 | 재사용·일반화 가능성 |
| 어려움 | 새 조건마다 데이터 추가 | 정렬·전이·안전 검증 |

넓은 모델이 항상 제품에 더 적합한 것은 아니다. 현장에서는 좁은 작업을 높은 신뢰도로 수행하는 시스템이 더 가치 있을 수 있다. 모델군을 읽을 때는 “얼마나 크고 유명한가”보다 “어떤 범위에서 어떤 실패를 감수하도록 설계되었는가”를 먼저 물어야 한다.
