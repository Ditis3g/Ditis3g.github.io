가상 창고에서 상자를 잘 집던 로봇이 실제 창고에서 실패할 수 있다. 현실에는 시뮬레이션에 없던 조명 변화, 센서 잡음, 마찰, 케이블 흔들림, 물체의 변형과 접촉이 있기 때문이다. 이 차이를 Reality Gap이라고 부른다.

## 현실은 하나의 차이가 아니다

| 차이의 종류 | 가상에서의 가정 | 현실에서 생기는 문제 |
| --- | --- | --- |
| 시각 | 일정한 조명과 선명한 물체 | 반사·그림자·노출 변화 |
| 센서 | 정확한 위치와 거리 | 지연·잡음·가림 |
| 물리 | 고정된 마찰과 강체 | 미끄러짐·변형·탄성 |
| 몸 | 알려진 질량과 관절 | 조립 오차·마모·케이블 영향 |
| 환경 | 비어 있는 작업 공간 | 사람·도구·예상 밖 물체 |

Reality Gap은 시뮬레이션이 쓸모없다는 증거가 아니다. 오히려 무엇을 가상에서 학습하고 무엇을 현실에서 반드시 검증해야 하는지를 구분하게 해 준다.

가상 정책을 현실에 배치할 때는 “성공했는가”만 보지 말고 어떤 차이에서 실패했는지 기록해야 한다. 그 기록은 시뮬레이션의 모델을 고치거나, 현실 입력을 정돈하거나, 정책이 변형을 견디도록 만드는 다음 단계의 재료가 된다.

## Reality Gap은 하나의 틈이 아니다

가상과 현실의 차이를 “그래픽이 덜 사실적이다”라고만 말하면 중요한 원인을 놓친다. 현실에서 실패하는 이유는 영상의 색뿐 아니라 시간 지연, 몸의 마찰, 센서의 가림, 물체의 변형, 사람의 예측 불가능한 움직임처럼 서로 다른 층에 걸쳐 있다.

이렇게 분해하면 “현실과 똑같은 시뮬레이터”라는 막연한 목표 대신, 이번 작업에서 어떤 차이가 성공을 좌우하는지 정할 수 있다. 빠른 이동이라면 시간 지연과 센서 주기가 중요하고, 섬세한 파지라면 마찰과 접촉 모델이 중요할 수 있다.

| 차이의 층 | 시뮬레이션에서의 가정 | 현실에서 나타나는 차이 |
| --- | --- | --- |
| 관측 | 깨끗한 영상·정확한 깊이 | 노이즈·노출·가림·지연 |
| 물체 | 질량·형상·마찰이 고정 | 변형·표면 편차·미끄러짐 |
| 몸 | 정확한 관절·모터 모델 | 조립 오차·마모·케이블 영향 |
| 시간 | 일정한 주기와 즉시 반응 | 통신·계산·센서 지연 |
| 환경 | 비어 있고 반복 가능한 장면 | 사람·도구·예상 밖 물체 |

## 전이 실패를 진단하는 순서

현실에서 실패한 장면을 가상 장면과 나란히 놓고 먼저 관측이 달랐는지, 그다음 몸의 실제 궤적이 달랐는지, 마지막으로 정책의 선택이 달랐는지 확인한다. 관측이 이미 달랐다면 정책을 탓하기 전에 입력의 대응을 고쳐야 한다. 입력은 같았는데 결과가 달랐다면 물리 모델이나 제어를 점검해야 한다.

```text
현실 실패
   ↓
관측이 가상과 달랐나? ─ 예 → 센서·렌더링·환경 보정
   │ 아니오
몸의 움직임이 달랐나? ─ 예 → 물리·제어·지연 보정
   │ 아니오
정책 선택이 달랐나?   ─ 예 → 데이터·강건성·재학습
```

이 진단표는 모든 실패를 모델 재학습으로 보내지 않게 해 준다. 전이는 모델만의 문제가 아니라 입력·몸·환경·운영이 함께 만드는 시스템 문제다.

## 함께 읽는 보충 내용 — 시뮬레이션을 현실에 가깝게 만드는 방법

첫 번째 전략은 연습장을 현실에 가깝게 만드는 것이다. 실제 장면을 스캔해 배치와 시야를 재현하고, 로봇의 질량과 관절 범위, 도구의 크기와 접촉 조건을 맞춘다.

## 무엇을 닮게 만들어야 하는가

모든 요소를 똑같이 자세히 만들 필요는 없다. 작업 성공에 영향을 주지 않는 벽의 질감보다 카메라의 시야와 작업대의 높이가 중요할 수 있다. 반대로 충돌이 핵심인 작업에서는 외형보다 충돌 형상과 관절 범위가 중요하다. 정밀도는 장면 전체에 균등하게 투자하는 것이 아니라 실패를 만드는 요소에 집중해야 한다.

| 작업의 민감한 요소 | 우선 모델링할 것 |
| --- | --- |
| 시각적 선택 | 카메라 노출·시야·가림·색 변형 |
| 파지 | 물체 형상·마찰·그리퍼 접촉 |
| 이동 | 바닥·충돌·관절 한계·지연 |
| 사람 협업 | 사람의 위치·속도·안전 영역 |

## 현장 데이터를 모델의 기준으로 사용하기

시뮬레이션을 처음부터 완벽하게 설계하기보다, 실제 현장에서 대표 장면과 실패를 측정해 가상 모델의 기준을 잡는 편이 효율적이다. 카메라의 실제 노출과 깊이 오차를 확인하고, 로봇이 명령을 받은 뒤 손끝이 어떻게 늦게 움직이는지 기록하며, 물체를 잡을 때 힘이 어떻게 변하는지 측정한다.

이때 현장 데이터는 단순한 테스트 세트가 아니다. 어떤 가상 변수를 어느 범위로 설정할지 알려 주는 모델링 자료다. 측정하지 않은 변동을 임의로 크게 넣으면 비현실적인 연습장이 되고, 너무 좁게 넣으면 현실의 꼬리를 놓친다.

## 가깝게 만든 시뮬레이터의 사용법

정밀한 모델은 하나의 답을 내놓는 도구가 아니라 가설을 비교하는 도구다. 카메라 위치를 바꾸기 전후의 가림 정도를 비교하고, 그리퍼 재질을 바꿨을 때 파지 여유가 얼마나 늘어나는지 확인하고, 새 작업대 배치에서 도달 불가능한 구간을 찾는다. 이렇게 사용하면 시뮬레이션의 가치는 모델의 외형이 아니라 설계 결정을 빠르게 검토하는 데서 나온다.

| 모델링 대상 | 맞춰야 하는 이유 |
| --- | --- |
| 카메라 위치와 시야 | 같은 물체가 화면에서 보이는 위치가 달라짐 |
| 로봇 몸과 관절 | 같은 명령도 손끝 궤적이 달라짐 |
| 도구의 형상 | 접촉점과 파지 가능 영역이 달라짐 |
| 물체의 질량과 마찰 | 미끄러짐과 힘의 결과가 달라짐 |
| 작업 공간 배치 | 접근 경로와 충돌 후보가 달라짐 |

이 전략은 특정 현장을 재현하는 데 강하다. 가상 창고에서 실제 선반과 로봇을 미리 배치해 보고, 카메라 사각지대와 도달하지 못하는 위치를 발견할 수 있다.

하지만 현실을 아무리 정밀하게 모델링해도 모든 변형을 맞출 수는 없다. 실제 물체의 표면과 조명은 계속 바뀌고, 모델링하지 않은 케이블과 사람의 움직임이 나타난다. 현실에 가깝게 만드는 전략은 중요한 조건을 맞추는 출발점이지, 현실을 완전히 복제하는 방법은 아니다.
