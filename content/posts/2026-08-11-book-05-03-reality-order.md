전이를 시뮬레이션의 문제로만 보면 현실의 작업 공간이 바뀌지 않는다는 전제를 놓친다. 카메라의 위치를 표준화하고, 조명과 작업대의 반사를 관리하고, 물체가 놓이는 범위를 제한하면 모델이 배워야 할 변형을 줄일 수 있다.

## 현실을 정돈한다는 뜻

환경을 정돈하는 것은 학습 범위를 설계하는 일이다. 모든 현실을 그대로 받아들이는 것이 항상 좋은 자동화는 아니다. 물체가 놓이는 영역을 표시하고, 카메라를 흔들리지 않게 설치하고, 사람이 들어오는 경로를 분리하면 모델이 해결해야 할 문제 중 일부를 시스템 설계로 옮길 수 있다. 이때 줄어든 변동은 데이터와 검증을 더 중요한 변동에 집중하게 한다.

하지만 정돈은 금지 목록을 늘리는 방식이어서는 안 된다. 작업자가 실제로 자주 어기는 조건을 파악하지 않고 규칙을 세우면 현장은 규칙을 우회하거나 시스템을 사용하지 않게 된다. 표준화할 조건과 허용할 변형을 작업 흐름·안전·경제성 기준으로 함께 결정해야 한다.

| 정돈의 수준 | 장점 | 위험 |
| --- | --- | --- |
| 강한 표준화 | 빠른 도입·단순한 검증 | 예외에 약하고 작업 유연성 감소 |
| 제한된 변형 허용 | 일반화와 통제의 균형 | 어떤 변형을 허용할지 설계 필요 |
| 넓은 개방 환경 | 다양한 작업 가능 | 데이터·안전·검증 비용 증가 |

## 사람의 작업도 인터페이스의 일부다

현장을 모델이 다루기 쉽게 만든다는 말은 사람을 배제한다는 뜻이 아니다. 사람이 물체를 어디에 놓는지, 언제 로봇 영역에 손을 넣는지, 실패했을 때 어떤 신호를 보내는지를 인터페이스로 설계해야 한다. 예측 가능한 사람의 행동은 모델과 안전층이 처리할 수 있는 변동이 된다.

좋은 현장 설계는 사람에게 더 많은 규칙을 외우게 하기보다, 표식·동선·신호·작업대 구조로 자연스럽게 행동을 유도한다. 피지컬 AI의 성능은 모델 파라미터와 현장 설계가 함께 만든 결과다.

| 현장 설계 | 줄어드는 불확실성 |
| --- | --- |
| 카메라 위치 고정 | 시야와 물체 크기 변화 |
| 조명과 반사 관리 | 인식에 영향을 주는 밝기 변화 |
| 작업대 영역 표시 | 물체가 놓이는 범위 |
| 도구 규격 통일 | 접촉과 파지 방식 |
| 사람 동선 분리 | 갑작스러운 충돌 후보 |

이 방법은 AI가 부족해서 현실을 억지로 단순화하는 것이 아니다. 모든 자동화 시스템은 작업 범위를 정의하고, 장비와 공간을 설계하며, 안전 경계를 만든다. 피지컬 AI에서도 현실의 변동을 무한히 허용하는 것보다, 중요한 변동과 통제할 수 있는 조건을 구분하는 편이 운영에 유리하다.

다만 정돈된 환경이 너무 좁으면 새로운 조건에 대한 일반화가 줄어든다. 현장 표준화와 데이터 다양성 사이에서 어떤 변동을 허용할지 결정해야 한다.

## 함께 읽는 보충 내용 — 도메인 랜덤화와 강건한 정책

두 번째 전략은 현실을 정확히 하나 복제하는 대신, 현실에서 만날 수 있는 변형을 가상에서 많이 보여 주는 것이다. 조명, 색, 카메라 노이즈, 마찰, 물체 위치를 바꾸면 정책은 특정 장면의 겉모습보다 작업에 공통인 단서를 찾도록 압박받는다.

## 랜덤하게 바꾸면 모두 좋아지는가

무작위화에도 난이도가 있다. 처음부터 모든 변수의 범위를 크게 열면 정책은 어떤 조건도 충분히 배우지 못할 수 있다. 반대로 쉬운 장면만 반복하면 특정 환경의 단서에 과적합한다. 현실적인 과정은 기본 조건에서 시작해 정책이 안정되면 점차 어려운 변형을 추가하고, 성능이 무너지는 경계에서 다시 범위를 조정하는 것이다.

```text
기본 조건 → 작은 변형 → 성공 확인
     ↑                    ↓
     └── 실패 경계에서 난이도 조정
```

이 방식은 랜덤화의 양보다 학습 난이도의 순서를 관리한다. 조명과 색을 먼저 바꿀 수 있지만, 도달 불가능한 위치나 실제로 존재하지 않는 마찰을 넣는 것은 학습에 도움이 되지 않는다.

## 어려운 장면을 일부러 찾기

모든 변형을 같은 횟수로 샘플링하면 드물지만 치명적인 조건이 데이터에 묻힌다. 정책이 자주 실패하는 조명·자세·마찰 조합을 찾아 그 조건에 더 많은 학습과 평가를 배정하는 방식이 효율적이다. 이는 무작위화가 단순한 확률적 장면 생성이 아니라, 약점을 발견하고 집중하는 과정임을 뜻한다.

| 전략 | 데이터가 집중되는 곳 |
| --- | --- |
| 균등 랜덤화 | 미리 정한 전체 범위 |
| 실패 중심 샘플링 | 과거에 실패한 조건 |
| 난이도 상승 | 현재 성공 가능한 경계 근처 |
| 현장 기반 샘플링 | 실제 로그에서 자주 나타난 변형 |

강건한 정책은 모든 조건을 완벽히 처리하는 정책이 아니라, 중요한 변동을 만나도 목표를 유지하고 어려운 조건에서는 안전하게 중단할 줄 아는 정책이다.

그렇지 않다. 현실에서 일어나지 않는 변형을 너무 많이 넣으면 학습이 작업과 무관한 장면에 맞춰질 수 있다. 반대로 실제로 자주 발생하는 변형을 빼면 전이 때 취약점이 그대로 남는다.

| 선택 | 효과 | 주의점 |
| --- | --- | --- |
| 현실적인 조명 변형 | 특정 밝기에 과적합하는 것을 줄임 | 작업 단서가 사라지지 않아야 함 |
| 물체 위치 변형 | 위치 변화에 대응 | 도달 불가능한 위치는 제외 |
| 센서 잡음 추가 | 측정 오차에 견딤 | 실제 센서 특성과 맞아야 함 |
| 마찰 변형 | 접촉 조건 변화에 대응 | 안전한 힘 범위를 함께 검증 |

랜덤화는 현실을 모델에게 보여 주는 한 방법이지, 실제 데이터를 대체하는 만능 버튼이 아니다. 시뮬레이션에서 버틴 조건을 다시 현실의 대표 사례에서 확인해야 한다.
