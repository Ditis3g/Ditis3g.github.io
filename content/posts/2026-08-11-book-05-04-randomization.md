## 랜덤하게 바꾸면 모두 좋아지는가

무작위화에도 난이도가 있다. 처음부터 모든 변수의 범위를 크게 열면 정책은 어떤 조건도 충분히 배우지 못할 수 있다. 반대로 쉬운 장면만 반복하면 특정 환경의 단서에 과적합한다. 현실적인 과정은 기본 조건에서 시작해 정책이 안정되면 점차 어려운 변형을 추가하고, 성능이 무너지는 경계에서 다시 범위를 조정하는 것이다.

```text
기본 조건 → 작은 변형 → 성공 확인
     ↑                    ↓
     └── 실패 경계에서 난이도 조정
```

이 방식은 랜덤화의 양보다 학습 난이도의 순서를 관리한다. 조명과 색을 먼저 바꿀 수 있지만, 도달 불가능한 위치나 실제로 존재하지 않는 마찰을 넣는 것은 학습에 도움이 되지 않는다.

## 어려운 장면을 일부러 찾기

모든 변형을 같은 횟수로 샘플링하면 드물지만 치명적인 조건이 데이터에 묻힌다. 정책이 자주 실패하는 조명·자세·마찰 조합을 찾아 그 조건에 더 많은 학습과 평가를 배정하는 방식이 효율적이다. 이는 무작위화가 단순한 확률적 장면 생성이 아니라, 약점을 발견하고 집중하는 과정임을 뜻한다.

| 전략 | 데이터가 집중되는 곳 |
| --- | --- |
| 균등 랜덤화 | 미리 정한 전체 범위 |
| 실패 중심 샘플링 | 과거에 실패한 조건 |
| 난이도 상승 | 현재 성공 가능한 경계 근처 |
| 현장 기반 샘플링 | 실제 로그에서 자주 나타난 변형 |

강건한 정책은 모든 조건을 완벽히 처리하는 정책이 아니라, 중요한 변동을 만나도 목표를 유지하고 어려운 조건에서는 안전하게 중단할 줄 아는 정책이다.

그렇지 않다. 현실에서 일어나지 않는 변형을 너무 많이 넣으면 학습이 작업과 무관한 장면에 맞춰질 수 있다. 반대로 실제로 자주 발생하는 변형을 빼면 전이 때 취약점이 그대로 남는다.

| 선택 | 효과 | 주의점 |
| --- | --- | --- |
| 현실적인 조명 변형 | 특정 밝기에 과적합하는 것을 줄임 | 작업 단서가 사라지지 않아야 함 |
| 물체 위치 변형 | 위치 변화에 대응 | 도달 불가능한 위치는 제외 |
| 센서 잡음 추가 | 측정 오차에 견딤 | 실제 센서 특성과 맞아야 함 |
| 마찰 변형 | 접촉 조건 변화에 대응 | 안전한 힘 범위를 함께 검증 |

랜덤화는 현실을 모델에게 보여 주는 한 방법이지, 실제 데이터를 대체하는 만능 버튼이 아니다. 시뮬레이션에서 버틴 조건을 다시 현실의 대표 사례에서 확인해야 한다.
