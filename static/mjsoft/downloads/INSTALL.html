MjZip 0.2.0 설치 안내

  1. MjZip-0.2.0-setup-r3.exe를 다운로드하고 실행합니다.
  2. 설치 폴더와 파일 연결·클래식 우클릭 메뉴·바로가기 옵션을 선택합니다.
  3. 기본 앱 설정을 선택했다면 Windows 설정에서 MjZip을 지정합니다.

Windows x64용이며 .NET 런타임이 포함되어 있습니다. 현재 사용자에게 설치하며 기본 경로는 %LOCALAPPDATA%\Programs\MjZip입니다. 기존 설치와 같은 식별자를 사용해 업그레이드합니다.

Windows 설정의 설치된 앱에서 제거할 수 있습니다. Windows 11 새 우클릭 메뉴를 쓰려면 설치 옵션에서 기본 선택된 해당 항목을 유지하고 인증서 신뢰 등록 관리자 승인 창을 승인하세요. 자체 서명 인증서는 이 PC의 TrustedPeople 저장소에 등록되며, Root 저장소에는 등록하지 않습니다. 거절하면 새 메뉴 등록을 건너뜁니다. 앱 설정에서도 새 메뉴 등록을 다시 시도할 수 있습니다. 인증서 지문(SHA-1 식별자): 06DF39C92E978A28259CA8A7B200B333699D92A5. 이는 공인 인증기관의 제작자 검증이나 SmartScreen 평판을 대신하지 않습니다. 클래식 메뉴는 추가 옵션 표시에서 사용할 수 있습니다.

코드 서명이 없는 배포본입니다. 배포 출처와 SHA-256을 확인하세요. 설치 및 파일 연결 등록은 유료 라이선스 키 인증과 별개이며, 현재 별도 라이선스 키 인증 기능은 없습니다. 포함 라이브러리 고지는 설치 폴더의 THIRD-PARTY-NOTICES.md 및 licenses 폴더에 있습니다.
