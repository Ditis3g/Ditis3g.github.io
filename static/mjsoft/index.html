MjZip작업을 더 가볍게.
어떤 PC에서 사용할 수 있나요?＋

Windows x64용 프로그램입니다. 자체 포함 배포본은 별도 .NET 설치 없이 실행할 수 있습니다. 현재 문서에는 구체적인 Windows 최소 버전이 확정되어 있지 않으므로, 공개 배포 전 지원 OS 범위를 추가로 안내할 예정입니다.

지금 다운로드할 수 있나요?＋

네. 이 페이지의 다운로드 버튼에서 MjZip 0.2.0 Windows x64 설치 파일을 받을 수 있습니다. .NET 런타임이 포함되어 있으며, 파일 연결과 클래식 우클릭 메뉴를 선택해 설치할 수 있습니다.

Windows 11 우클릭 메뉴용 서명은 꼭 필요한가요?＋

아니요. 별도로 서명한 MSIX 패키지는 Windows 11의 새 우클릭 메뉴에서 ‘압축 풀기’ 같은 명령을 바로 사용하는 선택적 탐색기 연동에 필요합니다. 이 연동을 사용하지 않으면 별도의 MSIX 서명·등록 없이 MjZip을 직접 실행해 압축하고 풀 수 있습니다. 현재 사용자용 클래식 우클릭 메뉴는 설정에서 선택할 수 있습니다. 이 패키지 서명 요건과 프로그램 이용·배포 라이선스는 서로 다른 사항입니다.

무료인가요? 회사에서도 사용할 수 있나요?＋

MjZip 자체 코드의 배포 라이선스는 아직 정해지지 않았습니다. 무료 사용이나 기업 사용 가능 여부는 현재 확정해 안내할 수 없으며, 공식 배포 시 이용 조건을 확인해주세요.

암호가 걸린 파일과 한글 파일명도 지원하나요?＋

ZIP의 AES-128/256·ZipCrypto와 7z의 AES 암호화·파일명 암호화를 지원합니다. 한글 파일명 판별 및 수동 문자셋 선택을 제공하며, UTF-8·CP949·Shift-JIS ZIP 파일명 처리가 검증되어 있습니다.

백신 연동만으로 모든 파일이 안전한가요?＋

아닙니다. AMSI 연동은 안전 보증이 아닙니다. 자동 검사는 위험 형식의 앞 16 MiB 또는 모든 파일의 앞 64 MiB까지이며, 수동 검사도 64 MiB 초과 항목은 미완료로 표시합니다. 백신 제공자가 없거나 오류가 나도 미완료로 안내합니다. 신뢰할 수 없는 파일은 실행하지 마세요.

지원하지 않는 기능도 있나요?＋

ALZ·EGG, SFX 제작, 손상 파일 복구, 암호 복구·관리, 외부 편집 후 압축파일 자동 반영, 자동 업데이트는 지원하지 않습니다. Windows 11 새 우클릭 메뉴 연동은 별도로 서명한 MSIX가 필요하며 기본 배포본에서 자동 등록하지 않습니다.
