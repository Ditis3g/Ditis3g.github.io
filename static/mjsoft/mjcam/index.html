결과창에서 복사 / Ctrl+C로 복사하세요. 새로 만들기 / Ctrl+N은 직전 방식을 유지하고, 옆 ▼에서 다른 방식을 선택합니다. 틀 캡처는 틀을 다시 조절한 뒤 촬영합니다.

설치가 필요한가요?＋

별도 설치 과정 없이 다운로드한 MjCam-1.0.2.exe를 실행합니다. Windows 10/11과 .NET Framework 4.8 이상을 권장합니다. 브라우저 안에서 작동하는 캡처 도구는 아닙니다. 기존 MjCam을 종료한 뒤 새 실행 파일을 열면 기존 설정과 저장 폴더를 이어 사용합니다.

캡처한 이미지는 어디에 저장되나요?＋

기본 저장 위치는 Windows 사진 폴더 안의 LightCapture 폴더입니다. 더보기의 설정에서 저장 폴더와 PNG/JPG 형식을 바꿀 수 있습니다. 틀 복사도 자동 저장하며, 스크롤 캡처와 부분 결과는 PNG로 저장합니다. 결과창을 닫은 뒤 하단의 파일 위치에서 저장 파일을 찾을 수 있습니다. 자동 저장 실패는 안내하며, 결과창에서 다른 이름으로 저장할 수 있습니다.

복사를 누르면 다시 캡처하나요?＋

결과창의 복사 또는 Ctrl+C는 표시된 이미지만 복사하며 파일을 중복 저장하지 않습니다. ‘틀 복사’는 새로 촬영해 자동 저장하고 클립보드에 복사하는 별도 동작입니다. 새로 만들기 / Ctrl+N은 직전 방식을 유지하며, ▼에서 다른 방식을 선택할 수 있습니다. 촬영 전 취소하면 이전 결과로 돌아옵니다.

확대 화면이나 파란 테두리도 저장되나요?＋

아니요. 영역 캡처의 돋보기·안내 문구와 선택 테두리는 결과에 포함되지 않습니다. 틀 캡처에서도 파란 테두리와 도구모음을 제외한 안쪽 화면만 저장합니다.

스크롤 캡처는 어떻게 사용하나요?＋

Chrome / Edge / Firefox에서 원하는 탭을 먼저 열고, MjCam의 스크롤 캡처를 누른 뒤 보이는 페이지 본문을 클릭하세요. 확장 설치나 영역 드래그 없이 본문 위치를 감지해 자동으로 스크롤합니다. 움직이는 영역은 검게 처리하며, 창·탭 전환이나 연결 실패로 중단되면 사유 팝업과 찍힌 부분을 보여줍니다. 페이지별 호환성은 아직 실사용 검증이 충분하지 않은 시험 기능으로, 모든 페이지의 전체 캡처를 보장하지 않습니다. 동영상 녹화·이미지 편집은 지원하지 않습니다.

실행할 때 보안 확인이 표시돼요.＋

배포 파일은 디지털 서명되지 않은 실행 파일입니다. Windows 또는 사내 보안 정책에 따라 실행이 제한될 수 있습니다. 보안 경고나 실행 제한을 우회하지 말고 담당 관리자에게 확인하세요. 다운로드 파일 검증용 SHA-256도 함께 제공합니다.
