아래는 제작 환경에서 확인한 범위입니다. 일부 파일이나 PC에서 동작한다는 결과가 모든 Windows·노트·입력기 환경의 호환을 뜻하지 않습니다.

기능상태확인 범위
한글 Markdown 저장구현·자동 검증한글·이모지 입력, UTF-8, CRLF·BOM의 파일 처리, 자동 저장
라이브·원문·읽기구현·앱 검증모드 전환, 제목·강조 표시, Markdown 읽기와 링크 이동
파일·폴더·탭구현·앱 검증생성, 이름 변경, 폴더 목록, 탭 열기·닫기
링크·별칭·백링크구현·자동 검증코드 속 연결 제외, 동명 노트 구분, 이름 변경 시 링크·앵커·별칭 보존
연결 그래프구현·앱 검증표시, 이동·확대 도구, 노트 필터. 표시 최대 1,000개
본문 검색구현·자동 검증1,000개 시험 노트의 한글 검색. 제작 PC 색인 약 0.31초, 검색 약 1ms. 환경·내용에 따라 달라짐
기존 보관함 복사구현·자동 검증원본·사본 해시 일치, 원본 유지, 설정 제외, 원본 안으로의 복사 차단
저장 충돌·복구구현·자동 검증변경 해시 충돌, 원본 유지, 복구 사본 재조회. 전체 전원 차단·디스크 손상 복구 보장은 아님
입력기·접근성추가 수동 확인 필요한글 텍스트 입력은 자동 검증. 실제 IME 조합, 화면 읽기 도구, 모든 고배율·다중 모니터 조합은 미검증
보안 경계구현·자동 검증경로 이탈·심볼릭 링크 차단, HTML 실행 차단, 외부 이미지 차단, 화면/파일 접근 격리

아직 제공하지 않는 기능

클라우드 동기화, 계정, 공동 편집, 모바일 앱, 외부 플러그인, Canvas, 수식 렌더링, 노트 임베드, 모든 Markdown 확장, 기존 앱 설정 가져오기는 범위에 포함되지 않습니다.

설계상 주의점

동일한 파일을 여러 앱에서 동시에 편집하는 상황을 완전한 파일 잠금으로 조정하지는 않습니다. 여러 파일의 이름·링크 갱신은 단일 원자적 트랜잭션이 아니므로 전원 차단 전에 모든 변경이 완료된다고 보장하지 않습니다. 같은 자료는 한 프로그램에서 편집하고 중요한 변경 전에는 별도 백업을 권장합니다.

이 배포물은 코드 서명되지 않은 개발 프리뷰입니다. 조직의 앱 설치 정책을 따르세요. MjNote는 독립적으로 구현되었으며 Obsidian과 제휴하거나 그 플러그인 호환을 보장하는 제품이 아닙니다.
