MJNOTE 0.1.0 · WINDOWS X64

첫 기록을 시작하기 전에.

MjNote는 사용자가 선택한 폴더의 Markdown 파일을 편집하는 Windows 앱입니다. 이 버전은 기능과 안정성을 확인하는 개발 미리보기입니다.

1. 설치하기

  1. 공식 소개 페이지에서 Windows x64 설치 파일을 받습니다.
  2. 다운로드한 파일의 이름과 제공된 SHA-256 값을 확인합니다. 조직의 보안·설치 정책을 따르세요.
  3. 설치 파일을 실행하고 설치 위치를 확인합니다. 현재 사용자 계정에 설치되며 필요한 실행 구성요소가 포함됩니다.
  4. 설치 후 시작 메뉴 또는 바로가기에서 MjNote를 실행합니다.

이 배포물은 코드 서명되지 않았습니다. 게시자 확인 또는 앱 보호 안내가 표시될 수 있습니다. 보안 정책으로 실행이 차단된다면 설정을 우회하지 말고 조직의 배포 담당자에게 확인하세요.

2. 노트 폴더 선택하기

  • 새 노트 폴더 만들기: 위치를 선택하면 새 폴더와 시작하기 노트를 만듭니다. 같은 이름이 있으면 새 이름을 사용합니다.
  • 기존 폴더 열기: 해당 폴더의 .md 파일을 직접 편집합니다. 편집하면 그 파일이 변경됩니다.
  • 기존 보관함을 사본으로 가져오기: 원본과 복사할 위치를 차례로 선택합니다. 원본 밖에 새로운 폴더를 만들고 사본을 엽니다. 처음 시험할 때는 이 방식을 권장합니다.

가져오기 대상은 Markdown과 PNG/JPEG/GIF/WebP 이미지입니다. 숨김 파일·설정·플러그인·심볼릭 링크와 기타 첨부 형식은 제외되며 결과에서 제외 개수를 확인할 수 있습니다.

3. 쓰고 연결하기

  • 새 노트: Ctrl+N 또는 왼쪽 새 노트 버튼. 저장 폴더와 이름을 선택합니다.
  • 편집 모드: 상단의 라이브 편집, Markdown 원문, 읽기 버튼으로 바꿉니다.
  • 전체 검색: Ctrl+Shift+F. 현재 노트 안에서는 Ctrl+F를 사용합니다.
  • 연결: [[노트 이름]], [[폴더/노트#제목|별칭]] 또는 상대 경로 Markdown 링크를 사용합니다.
  • 이동: 편집 중에는 Ctrl+클릭, 읽기 모드에서는 클릭으로 연결된 노트를 엽니다. 동명 노트는 선택 목록을 표시합니다.
  • 그래프: Ctrl+G. 끌기, 확대·축소, 필터, 노드 클릭으로 살펴봅니다.
  • 이름 변경: 노트 이름 변경 버튼에서 링크 변경 미리보기를 확인한 다음 실행합니다.

4. 저장과 복구

입력을 멈추면 자동 저장하며 Ctrl+S로 바로 저장할 수도 있습니다. 하단의 저장 상태를 확인하세요. 다른 프로그램에서 변경된 내용이 감지되면 덮어쓰지 않고 안내합니다. 그때는 현재 편집을 새 노트로 보관하거나, 편집 내용을 버리고 외부 파일을 다시 읽을 수 있습니다.

앱 종료 시 저장을 마치도록 시도합니다. 저장에 실패한 경우 돌아가서 해결하거나 복구 사본을 보관한 뒤 종료할 수 있습니다. 다음에 같은 노트를 열면 복구 사본이 표시됩니다. 복구 내용은 별도 노트로 보관하거나 버릴 수 있습니다.

복구 사본과 직전 저장본은 장기 백업이 아닙니다. PC·디스크 고장이나 여러 파일 작업 도중의 전원 차단을 모두 복구한다고 보장하지 않습니다. 중요한 보관함은 다른 저장장치에도 정기적으로 백업하세요.

5. 파일과 개인정보

노트는 선택한 폴더의 UTF-8 .md 파일입니다. 작업 공간과 복구 사본은 Windows 사용자 앱 데이터의 MjNote 폴더에 보관합니다. 계정·동기화·원격 측정·자동 업로드 기능은 없습니다. 외부 이미지 주소는 자동으로 불러오지 않습니다. 외부 웹 링크는 확인 후 엽니다.

6. 제거하기

Windows 설정의 앱 목록에서 MjNote를 선택해 제거합니다. 사용자가 선택한 노트 폴더와 로컬 복구·설정 데이터는 자동 삭제하지 않습니다. 파일을 정리하려면 먼저 필요한 노트와 복구 사본을 별도로 보관하세요.

현재 제한

노트당 2 MiB, 전체 색인 20,000개·약 128 MiB, 검색 결과 100개, 그래프 1,000개 제한이 있습니다. 플러그인, Canvas, 동기화, 수식, 노트 임베드 및 모든 Markdown 확장을 지원하지 않습니다. 자세한 내용은 구현·검증 상태를 확인하세요.
