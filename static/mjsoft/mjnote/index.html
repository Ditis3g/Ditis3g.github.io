내 파일과 첫 사용에 대해.

MjNote작은 기록, 새로운 연결.
어떤 PC에서 사용할 수 있나요?＋

Windows 10/11의 x64 PC를 대상으로 합니다. 필요한 실행 구성요소가 설치 파일에 포함되며 별도 런타임 설치는 필요하지 않습니다. 32비트와 ARM 네이티브 버전은 제공하지 않습니다. 모든 Windows·IME 조합의 검증을 마친 정식 버전은 아닙니다.

인터넷이나 회원 가입이 필요한가요?＋

설치 파일을 받은 뒤에는 계정 없이 오프라인으로 노트를 편집할 수 있습니다. 노트를 서버에 자동 업로드하지 않으며, 동기화나 사용 통계 전송 기능도 없습니다. 노트 안의 외부 웹 링크를 열 때만 별도로 확인합니다.

기존 Obsidian 보관함을 가져올 수 있나요?＋

Markdown과 PNG/JPEG/GIF/WebP 이미지의 사본을 새 폴더로 가져올 수 있습니다. 원본은 변경하지 않습니다. 숨김 설정, 플러그인, 심볼릭 링크, 기타 첨부 형식은 제외됩니다. Canvas·플러그인·동기화·모든 Markdown 확장과의 호환을 의미하지 않습니다. MjNote는 별도로 구현한 독립 앱입니다.

노트가 변경되거나 저장에 실패하면 어떻게 되나요?＋

입력을 멈추면 자동 저장하며 복구 사본과 직전 저장본을 앱의 로컬 데이터 영역에 보관합니다. 다른 프로그램의 변경이 발견되면 덮어쓰지 않고 알립니다. 편집 내용을 새 노트로 보관하거나 외부 파일을 읽을 수 있습니다. 별도의 장기 백업을 대체하지 않으므로 중요한 보관함은 따로 백업해 주세요.

현재 지원 범위와 제한이 있나요?＋

노트당 2 MiB, 전체 색인 20,000개·약 128 MiB, 검색 결과 100개, 그래프 1,000개 제한이 있습니다. 파일명 변경은 같은 폴더 안에서 지원합니다. 클라우드 동기화, 플러그인, Canvas, 수식 렌더링, 모바일 앱은 이번 버전의 범위에 포함되지 않습니다. 기능별 검증 상태를 확인하세요.

설치할 때 게시자 확인 안내가 나오나요?＋

현재 설치 파일은 코드 서명되지 않은 0.1.0 개발 프리뷰입니다. Windows에서 확인되지 않은 게시자 또는 앱 보호 안내를 표시할 수 있습니다. 설치 전 제공 경로와 SHA-256을 확인하고 조직의 앱 설치 정책을 따르세요. 보안 설정을 끄거나 우회할 필요는 없습니다.
