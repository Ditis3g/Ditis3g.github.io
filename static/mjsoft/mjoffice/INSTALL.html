MjOffice 0.3.2 · Windows x64 설치형

MjOffice 0.3.2 다운로드 ↓

다운로드 크기: 34.3 MiB

바탕화면과 시작 메뉴에 MjOffice 아이콘이 추가됩니다.

화면 실행 구성 요소가 없는 PC에서는 첫 설치 시 인터넷 연결이 필요합니다.

시작하는 방법

  1. MjOffice 설치 파일(.exe)을 PC에 내려받습니다.
  2. 설치 파일을 실행하고 안내에 따라 설치합니다.
  3. 바탕화면의 MjOffice 아이콘을 더블클릭합니다.
  4. 열린 MjOffice 창에서 Writer·Sheets·Slides를 사용합니다. 창을 닫으면 앱도 종료됩니다.

업데이트와 작업 백업

업데이트 전에 작업 공간의 내보내기에서 MjOffice 파일(.mjoffice)로 작업 내용을 백업하세요. 새 설치 파일을 실행하면 앱을 업데이트할 수 있습니다. 업데이트 전에 열려 있는 MjOffice 창을 닫아 주세요.

기존 ZIP 실행형이나 일반 브라우저에서 작성한 작업은 자동으로 이동하지 않습니다. 기존 작업 공간에서 백업한 .mjoffice 파일을 새 MjOffice 창에서 가져오세요. 원본 문서와 내보낸 결과 파일도 함께 보관하세요.

파일과 고지 확인

설치 폴더의 core/licenses에 포함 구성요소의 라이선스와 고지가 들어 있습니다. 앱 제거는 Windows 설정의 설치된 앱에서 할 수 있습니다.
