궁금한 이야기.

현재 사용할 수 있는 범위를 확인하세요.

MjOffice문서를 쓰는 일, 조금 더 자연스럽게.
어떤 PC에서 사용할 수 있나요?＋

Windows x64용 실행 구성을 제공합니다. MjOffice를 실행하면 로컬 작업 공간에서 Writer·Sheets·Slides를 사용할 수 있습니다.

지금 다운로드할 수 있나요?＋

MjOffice 0.3.2 Windows x64 설치 파일을 제공합니다. 설치 후 바탕화면의 MjOffice 아이콘을 누르면 전용 창에서 바로 사용할 수 있습니다.

어떤 파일을 가져올 수 있나요?＋

현재 DOCX 문서, XLSX 통합 문서, PPTX 프레젠테이션을 가져와 편집하는 경로가 있습니다. 복잡한 서식이나 일부 편집 기능은 파일에 따라 제한이 있습니다.

가져온 원본 파일은 자동으로 바뀌나요?＋

가져온 디스크 원본을 자동으로 덮어쓰지 않습니다. 작업 공간의 편집 사본과 원본 파일은 구분되며, 다른 곳에서 사용할 결과는 내보내기로 저장하세요.

작업 내용을 통째로 백업할 수 있나요?＋

내보내기의 MjOffice 파일(.mjoffice)로 작업 내용을 백업하고 다시 가져올 수 있습니다. 원본 형식으로 내보낸 파일과 작업 공간 백업은 목적이 다릅니다.

기존 Office와 모든 기능이 같나요?＋

현재 제공하는 기능과 파일별 지원 범위에는 차이가 있습니다. 원본을 보관하고 편집 사본에서 내용을 확인한 뒤 결과를 저장하세요.
