# 압축 안의 사진 보기

MjSee 0.30 개발 프리뷰. 기준일: 2026-10-29.

Ctrl+O, 파일 끌어놓기, 주소 입력 또는 실행 옵션에서 압축파일을 선택하세요. 안에 있는 지원 사진을 자연 정렬하고, 필요한 사진만 읽습니다. 원본 압축파일을 바꾸거나 ISO/UDF를 드라이브로 마운트하지 않습니다.

## 추가 형식의 현재 범위

| 형식 | 확인한 읽기 경로 | 남아 있는 제한 |
|---|---|---|
| CAB | 무압축 저장, MSZIP, LZX. 자체 생성 PNG·Windows 생성 파일 및 공개 텍스트 표본 | 분할 CAB는 현재 연결하지 않음. Quantum·특수 캐비닛 변형 추가 검사 필요 |
| LZH / LHA | 헤더 0~2의 공개 표본, 저장/LH5/6/7 실제 압축 해제. 저장 및 LH4~7 합성 PNG 표시 | **헤더 레벨 3은 미지원**. LH1 등 다른 방식·특수 파일명 인코딩·대형 실제 앨범 추가 검사 필요 |
| ISO | ISO 9660/Joliet, 한글 파일·하위 폴더 | Rock Ridge·멀티세션·복잡한 실제 광학매체 추가 검사 필요 |
| UDF | Windows 생성 1.02/2.01 및 ISO/Joliet/UDF 혼합 이미지 | 다른 리비전·VAT/희소 파일·실제 매체 변형 추가 검사 필요 |
| ALZ | 저장·Deflate·변형 BZip2(DLZ), ZipCrypto, CP949/UTF-8 이름·암호, 분할 조각 연결 | 첫 `.alz` 파일을 선택. 모든 제작 버전·손상 파일 복구·파일명 인코딩의 모호한 경우 추가 검사 필요 |
| EGG | 저장·Deflate·BZip2·AZO·LZMA, ZipCrypto·AES128/256·LEA128/256, 솔리드·분할, UTF-8/CP949·상대 이름·POSIX 시간 | 암호화된 파일명/전역 머리글은 미지원. 모든 제작 버전·조합·대형 실제 앨범은 미검증 |

혼합 ISO에서는 UDF를 먼저 확인하고 없으면 ISO/Joliet로 읽습니다. 디스크 전체를 메모리나 임시 폴더에 복사하지 않습니다. ZPAQ는 아직 미지원이며, 기존 ZIP/RAR/7Z/TAR 등의 읽기는 기존 경로를 유지합니다. ZIPX/ZST의 모든 방식이 검증된 것은 아닙니다.

## ALZ·EGG 암호와 분할 압축

- 암호가 필요한 사진은 ‘암호 입력’을 눌러 엽니다. 암호는 실행 중에만 제한된 개수로 기억하며 설정이나 압축파일에 기록하지 않습니다. 메뉴 → 압축파일에서 기억한 암호를 잊을 수 있습니다.
- ALZ의 `.alz`, `.a00`, `.a01` 등 모든 조각을 같은 폴더에 두고 첫 `.alz`를 선택하세요. 명시된 분할 꼬리표·버전·볼륨 번호가 맞아야 연결하며, 단일 ALZ와 이름만 비슷한 다른 파일은 열지 않습니다.
- 분할 EGG는 같은 폴더의 `.egg` 조각 안에 있는 고유 ID와 앞뒤 연결을 확인합니다. 첫 조각뿐 아니라 중간 조각을 선택해도 연결할 수 있습니다. 조각이 없거나 같은 ID가 중복되면 자동으로 임의의 파일을 고르지 않습니다.
- 한 번의 열기/드롭에 같은 EGG의 여러 조각을 넣으면 사진을 한 번만 표시합니다. 먼저 선택한 조각의 경로는 유지하며, 별개의 열기 요청·즐겨찾기 항목·이웃 폴더 이동 전체에 걸친 동일 묶음 통합은 아직 추가 개선 대상입니다.
- 솔리드 EGG는 파일 사이에 압축 상태를 공유하므로 앞쪽 데이터를 읽어야 하며, 무결성 확인을 위해 선택 사진 뒤의 데이터도 처리할 수 있습니다. 큰 솔리드 앨범에서는 사진 이동 시간이 더 길어질 수 있습니다.
- AES/LEA의 검증 태그가 있는 경우 암호문의 HMAC를 먼저 검사하고, 해제 결과의 길이와 CRC도 확인합니다. 검증 태그가 없는 구형 파일은 길이·CRC 검사에 의존합니다. ZipCrypto나 구형 파일의 보안 강도를 현대적인 암호화와 동등하다고 안내하지 않습니다.
- 압축 조각을 외부에서 교체한 뒤에는 목록을 새로고침하세요. 파일 변경 감지는 읽기 요청 중 사용한 조각의 크기·수정일·생성일 기준이며, 모든 조각을 상시 감시하는 기능은 아닙니다.

## 평소 사용 방법

- 썸네일·상세 목록, 이전/다음, 두 장/네 장 비교, 웹툰 보기와 슬라이드쇼를 기존 메뉴와 단축키로 이용합니다.
- 즐겨찾기에는 압축파일과 그 안의 정확한 항목 위치를 보관합니다. 압축파일을 이동하거나 항목 이름을 바꾸면 재연결이 필요합니다.
- F3에서 사진·압축파일을 추가하거나 현재 목록을 변환합니다. 사진별 편집·출력 위치·이름을 확인하고 내보내기를 시작하세요.
- 사진 정리함의 복사/이동 작업은 압축 안의 사진을 **원래 바이트로 꺼내기만** 합니다. 원본 압축의 사진을 삭제하지 않으며, 같은 출력 이름은 번호를 붙여 보존합니다.
- 내부 경로의 대소문자를 구분합니다. 같은 정확한 이름이 중복된 경우에는 첫 항목만 목록에 표시합니다. 파일시스템 링크·대체 스트림·삭제 항목은 일반 사진으로 따라가지 않습니다.

## 안전 제한과 자원 사용

추가 형식은 별도의 읽기 작업 하나에서 처리합니다. 사진 파일 경로나 암호를 외부 사이트로 전송하지 않으며, 압축 항목 이름으로 파일을 생성하지 않습니다. 요청 정보는 비공개 스트림으로만 전달하고 명령줄·작업 요청 파일·로그에 기록하지 않습니다.

- 압축 항목: 100,000개, 목록 내 이름의 UTF-8 합계 8MiB.
- 사진 한 개: 512MiB. 선언 크기뿐 아니라 실제 출력 크기도 검사합니다.
- 요청당 실제 입력 읽기·솔리드 순차 처리: 1GiB. 디스크 이미지 전체의 논리 크기를 1GiB로 제한하는 것은 아닙니다.
- ALZ/EGG의 조각은 최대 1,000개. EGG 조각을 찾을 때 같은 폴더만 확인하고, 폴더 항목 100,000개/후보 `.egg` 4,096개로 제한합니다. 보조 조각의 연결 파일은 따라가지 않습니다.
- ALZ/EGG 블록도 최대 100,000개. AZO 한 블록의 해제 크기는 256MiB, LZMA 사전은 128MiB, ALZ DLZ의 BWT 블록은 900,000바이트로 제한합니다. 암호화 파일의 인증을 위해 읽은 바이트도 입력 한도에 포함합니다.
- 요청 시간: 최대 45초. 내부 진행 검사에도 40초 제한이 있습니다.
- 별도 읽기 작업 메모리: 768MiB, 하위 프로세스 생성 금지, 누적 CPU 90초 제한. 재사용 전 누적 CPU 45초/128요청에서 갱신합니다.
- 원본 핸들은 요청마다 닫습니다. 읽는 동안 파일이 변경된 것이 감지되면 성공 처리하지 않고 새로고침을 안내합니다. 파일 크기·수정일·생성일 비교이며 악의적인 동시 변경을 완벽히 검출한다는 의미는 아닙니다.
- 반복 요청에는 실행 준비 비용을 줄이도록 작업을 재사용하고, 마지막 사용 후 약 15~30초의 유휴 상태에서 종료합니다. 이 계층에 압축 해제 사진을 별도로 보관하지 않습니다. 기존 사진 캐시는 사용자 설정 예산을 따릅니다.

취소/오류/출력 실패 후에는 남아 있는 응답을 다음 요청으로 잘못 읽지 않도록 해당 작업을 닫고 다음 요청에서 새로 시작합니다. 실패한 변환·꺼내기는 최종 출력으로 확정하지 않습니다. 자원 제한과 오류 격리는 제공하지만 운영체제의 완전한 보안 샌드박스는 아닙니다.

## 오류가 표시되면

- **LHA 헤더 레벨 3:** 현재 읽기 모듈의 알려진 미지원입니다. 원본 손상으로 단정하지 않습니다.
- **다른 분할 조각 필요:** ALZ·EGG는 위 방식으로 같은 폴더의 조각을 연결합니다. 분할 CAB 등 다른 추가 형식은 아직 연결하지 않습니다.
- **파일명 암호화:** 파일명/전체 머리글 암호화 EGG는 현재 알려진 미지원입니다. 일반적인 파일 내용 암호화와 구분해 안내합니다.
- **무결성 검사 실패:** 암호가 맞는지, 조각이 섞이거나 압축 데이터가 손상되지는 않았는지 확인하세요. 불완전한 출력은 성공한 파일로 저장하지 않습니다.
- **파일이 바뀜:** 저장/교체가 끝난 뒤 목록을 새로고침하세요.
- **용량·시간 초과:** 필요한 사진을 별도 폴더에 꺼낸 뒤 열거나 크기가 작은 압축으로 나누어 확인하세요.
- **추가 읽기 파일 없음:** 실행 파일만 복사하지 말고 MjSee 배포 폴더의 DLL·하위 폴더를 함께 보관하세요.

## 구성 요소와 출처

Igor Pavlov의 [7-Zip 공식 26.05 배포](https://www.7-zip.org/download.html)의 unmodified x64 `7z.dll`(1,908,736바이트)을 별도로 읽습니다. 저작권·LGPL/BSD/unRAR 고지, 완전한 동일 버전 소스와 호환 라이브러리 교체 설명을 배포 폴더에 포함합니다. 설치 프로그램이나 탐색기 확장은 실행/설치하지 않았습니다. [제3자 고지](../THIRD_PARTY.md)를 확인하세요.
