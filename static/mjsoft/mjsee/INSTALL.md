# MjSee 0.33 설치 안내

## 설치하기

`MjSee-0.33.0-Setup-x64.exe` 한 파일로 설치합니다. 설치 중 인터넷 다운로드나 별도 런타임 설치가 필요하지 않습니다. 선택형 AI 모델은 기존과 같이 해당 기능을 처음 사용할 때 사용자의 확인 후 별도로 다운로드합니다.

1. 설치된 MjSee를 업데이트하는 경우 그 프로그램 창을 먼저 닫습니다. 현재 작업 폴더에서 실행하던 이전 휴대용 버전은 자동으로 종료하거나 덮어쓰지 않습니다.
2. 설치 파일을 실행하고 안내에 따라 설치 위치를 선택합니다. 기본 위치는 현재 사용자의 로컬 프로그램 폴더 아래 `MjSee`입니다.
3. 바탕 화면 바로가기는 원하는 경우 선택합니다. 시작 메뉴에는 MjSee와 제거 바로가기가 생깁니다.
4. 시작 메뉴의 **MjSee**를 열고 사진을 불러옵니다. 사진 우클릭 또는 상단 **전체 기능**에서 편집·AI·변환·인쇄·파일 정리를 찾을 수 있습니다.

Windows x64, Windows 10 2004(빌드 19041) 이상 또는 Windows 11용입니다. 관리자 권한과 계정 가입은 필요하지 않습니다. Windows ARM·32bit용 설치 파일은 아닙니다.

설치 파일은 약 64MB, 설치 후 프로그램은 실행 구성요소를 포함해 약 212MB입니다. 사진과 선택형 AI 모델의 저장 공간은 별도입니다.

## 설치 범위와 재설치

- 현재 사용자에게만 설치합니다. 시작 프로그램·예약 작업·서비스·방화벽 규칙을 추가하지 않습니다.
- 기본 사진 앱과 확장자 연결을 자동 변경하지 않습니다. 광고나 다른 제품을 설치하지 않습니다.
- 설치에 사용한 프로그램 파일만 관리합니다. 새 설치는 비어 있는 전용 폴더를 요구하며, 기존 휴대용 폴더나 일반 문서 폴더를 설치 위치로 사용하지 않습니다.
- 동일한 설치 폴더에는 같은 버전을 재설치할 수 있습니다. 더 높은 버전으로 표시된 기존 설치를 낮은 버전으로 덮어쓰지 않습니다.
- 기존 프로그램 파일의 잠금·접근 권한과 폴더 연결(정션/심볼릭 링크)을 미리 확인하고 문제가 있으면 변경 전에 중단합니다. 강제 종료나 재부팅 후 삭제를 예약하지 않습니다.
- 실제 파일을 쓰는 동안 저장 공간 부족·권한 변경·시스템 중단이 발생하면 설치가 부분 완료 상태로 남을 수 있습니다. 원인을 해결한 뒤 같은 설치 파일로 재설치할 수 있으며, 모든 실패의 자동 되돌리기를 보장하지는 않습니다.
- 이미 설치된 폴더에 관계없는 파일을 넣어 두었다면 제거 후에도 남을 수 있습니다. 사진은 설치 폴더가 아닌 사진 폴더에 보관하는 것을 권장합니다.

## 제거하기

Windows **설정 → 앱 → 설치된 앱 → MjSee → 제거**, 또는 시작 메뉴의 **MjSee 제거**를 사용합니다.

프로그램 파일과 설치한 바로가기를 제거합니다. 사진 원본, 사용자 설정, 즐겨찾기, 별도로 받은 AI 모델은 제거하지 않습니다. 설치 폴더 전체를 재귀적으로 지우는 방식은 사용하지 않습니다.

## 실행 확인과 현재 한계

설치본은 .NET / Windows Desktop Runtime 10.0.14를 포함합니다. 런타임이 포함되지 않은 기존 `release-0.33` 폴더 실행형과 구분합니다. 런타임 보안 패치가 나오면 포함 런타임을 갱신한 새 설치 파일을 배포해야 합니다.

이 파일은 개발 프리뷰이며 **코드 서명이 없습니다**. Windows에서 확인되지 않은 게시자 또는 앱 보호 안내가 표시될 수 있습니다. 보안 기능을 끄지 마세요. 회사 보안 정책에서 서명된 파일만 허용한다면 담당자의 배포 승인이 필요합니다.

검증은 실제 사용자 설치 목록·시작 메뉴·바탕 화면을 바꾸지 않는 별도 모드로 작업 폴더 안에서 수행합니다. 이 모드는 일반 설치의 동일 파일 추출·대상 검사·제거 코드를 사용하되 운영체제 등록과 바로가기 생성을 생략합니다. 실제 다른 PC에서의 대화형 설치, 기업 보안 정책, 전원 손실 중 복구는 추가 확인 대상입니다. 정확한 검사 결과는 [검증 기록](TESTING.md)에 구분해 남깁니다.
